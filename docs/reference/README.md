# Forts Technical Reference

The documentation here is **mostly** generated by LLMs during the development process. We've found that this is a good way to keep documentation **up to date**, though LLM generated docs are not the most **clear and concise** docs in the world. We hope you get the gist of forts by reading our hand-written docs before ever needing to dive in to the deep technical references. These docs are here primarily to provide context to agents, but you can read them too if you want.

## Internal references and jargon

Because agents contribute to the reference documentation automatically as a part of our development processes, you will very likely see references to internal issue numbers or activity.
